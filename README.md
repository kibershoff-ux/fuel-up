# Fuel Up ⚽

A simple, friendly food + protein tracker for Brylie. It's a web app you can install on a phone (PWA), and it's free to host on GitHub Pages.

- Logs are saved **only on the phone** (nothing is uploaded). Use **Me → Save backup** now and then.
- Food search: USDA FoodData Central (with Open Food Facts as a fallback). Barcode lookup: Open Food Facts.
- Grown-up settings (targets, optional weight check-ins) are behind a PIN on the **Me** tab.

Open: https://kibershoff-ux.github.io/fuel-up/
